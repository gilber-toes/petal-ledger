# Petal Ledger

A pastel spending diary for iPhone. Log daily spending in any currency, set a daily budget, mark no-spend days, and see weekly, monthly and yearly reports, with Gus cheering you on.

**Open it:** https://gilber-toes.github.io/petal-ledger/ in Safari, then tap **Share → Add to Home Screen**.

Your logs are saved only on your device (nothing is sent anywhere). Use **Settings → Back up data** now and then to keep a copy.

This folder is generated by `build_app.py`; edit the source and rebuild rather than editing `index.html` here.
